# PSICOMEDIC MS · Sitio web

Sitio web de **PSICOMEDIC & Mundo de Servicios** — soluciones integrales en salud
mental, bienestar social y salud ocupacional en Quito, Ecuador.

> *Tu salud mental importa. Cuidar de ti es el primer paso para dar lo mejor de ti.*

## 🧩 Estructura

```
PSICOMEDIC/
├── index.html          # Página principal
├── css/styles.css      # Estilos (paleta azul · celeste · blanco)
├── js/main.js          # Menú móvil, animaciones y formulario
├── imagenes/           # Logo e imágenes
├── firebase.json       # Configuración de Firebase Hosting
└── .firebaserc         # Proyecto Firebase asociado
```

## 🎨 Secciones

- Inicio (hero) · Nosotros / Historia · Misión y Visión
- Servicios (Psicología Empresarial, Clínica, Infantil, Medicina Ocupacional,
  Bienestar Laboral y Social)
- Valores · Contacto (formulario a WhatsApp) · Footer

## 🚀 Despliegue (Firebase Hosting)

```bash
firebase deploy --only hosting
```
